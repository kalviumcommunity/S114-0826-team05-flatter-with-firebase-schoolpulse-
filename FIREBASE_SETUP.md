# Firebase Setup Guide for SchoolPulse

## Prerequisites

1. Firebase project created in [Firebase Console](https://console.firebase.google.com)
2. FlutterFire CLI installed: `dart pub global activate flutterfire_cli`
3. Logged in to Firebase: `firebase login`

## Initial Configuration

### 1. Configure Firebase for your platforms

Run the FlutterFire configure command from the project root:

```bash
flutterfire configure
```

This will:
- Detect your Firebase project
- Generate `lib/firebase_options.dart` with real credentials
- Configure Android, iOS, Web, and desktop platforms

### 2. Enable Firebase Services

In Firebase Console, enable:
- **Authentication** → Email/Password provider
- **Cloud Firestore** → Start in test mode (we'll deploy rules later)
- **Storage** → Start in test mode (we'll deploy rules later)

### 3. Deploy Firestore Security Rules

```bash
# Install Firebase CLI if not already installed
npm install -g firebase-tools

# Login to Firebase
firebase login

# Deploy rules
firebase deploy --only firestore:rules
```

Or use the Firebase Console:
1. Go to Firestore → Rules
2. Copy contents of `firestore.rules`
3. Paste and publish

### 4. Deploy Firestore Indexes

```bash
firebase deploy --only firestore:indexes
```

Or create indexes manually in Firebase Console when prompted by errors.

### 5. Configure Storage Rules

In Firebase Console → Storage → Rules:

```javascript
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /{allPaths=**} {
      allow read, write: if request.auth != null;
    }
  }
}
```

For production, use more restrictive rules:

```javascript
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    // User profile photos
    match /users/photos/{userId}/{fileName} {
      allow read: if request.auth != null;
      allow write: if request.auth.uid == userId;
    }

    // School logos
    match /schools/logos/{schoolId}/{fileName} {
      allow read: if request.auth != null;
      allow write: if request.auth.token.admin == true ||
                         (request.auth.token.schoolAdmin == true && request.auth.token.schoolId == schoolId);
    }

    // Fee receipts
    match /fees/receipts/{feeId}/{fileName} {
      allow read: if request.auth != null;
      allow write: if request.auth != null;
    }

    // Student documents
    match /students/documents/{studentId}/{fileName} {
      allow read: if request.auth != null &&
                     (request.auth.uid == studentId ||
                      request.auth.token.admin == true ||
                      request.auth.token.schoolAdmin == true);
      allow write: if request.auth != null &&
                     (request.auth.uid == studentId ||
                      request.auth.token.admin == true ||
                      request.auth.token.schoolAdmin == true);
    }
  }
}
```

### 6. Set up Custom Claims for Roles

In Firebase Console → Authentication → Users, or via Admin SDK:

```javascript
// Set custom claims for a user
await admin.auth().setCustomUserClaims(uid, {
  role: 'districtAdmin',
  districtId: 'district_123',
  schoolId: 'school_456',
  admin: true,
  schoolAdmin: false,
  districtAdmin: true,
});
```

### 7. Create Initial Super Admin

1. Register a user via the app's registration page
2. In Firebase Console → Authentication → Users, copy the UID
3. Run in Firebase Console → Functions or Admin SDK:

```javascript
await admin.auth().setCustomUserClaims(uid, {
  role: 'superAdmin',
  admin: true,
  districtAdmin: true,
  schoolAdmin: true,
  teacher: true,
  viewer: true,
  permissions: ['*'],
});
```

### 8. Test the Application

```bash
# Run on web
flutter run -d chrome

# Run on Android
flutter run -d android

# Run on iOS
flutter run -d ios
```

## Common Issues

### "Missing or insufficient permissions"
- Check Firestore rules are deployed
- Verify user has correct custom claims
- Ensure user document exists in Firestore

### "Index not found"
- Deploy `firestore.indexes.json`
- Or create index via Firebase Console link in error message

### "Storage permission denied"
- Check Storage rules in Firebase Console
- Verify user is authenticated

### "FirebaseApp not initialized"
- Ensure `firebase_options.dart` has real config (not placeholders)
- Run `flutterfire configure` again if needed

## Production Considerations

1. **Enable App Check** for production apps
2. **Set up monitoring** with Firebase Performance
3. **Configure backup** for Firestore
4. **Review and tighten** security rules
5. **Set up alerting** for errors
6. **Enable offline persistence** for better UX

## Useful Commands

```bash
# Regenerate firebase_options.dart
flutterfire configure --project=your-project-id

# Deploy everything
firebase deploy

# View logs
firebase functions:log

# Test rules locally
firebase emulators:start
```
