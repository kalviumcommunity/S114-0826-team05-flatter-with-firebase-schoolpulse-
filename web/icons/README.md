# Icons

Replace these placeholder files with actual PNG icons:

- `Icon-192.png` - 192x192px app icon
- `Icon-512.png` - 512x512px app icon
- `dashboard.png` - 192x192px dashboard shortcut icon
- `schools.png` - 192x192px schools shortcut icon

The SVG files (`Icon-192.svg`, `Icon-512.svg`) can be used as references for generating the PNG files.

You can use tools like:
- https://www.fluttericons.com/
- https://icon.kitchen/
- https://www.pngwing.com/
- Flutter's `flutter_launcher_icons` package

Run `flutter pub run flutter_launcher_icons:main` after configuring in pubspec.yaml to generate all required icons.
